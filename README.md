# STICKMAN DUEL ARENA

Физический 2D-файтинг со стикменами (HTML5 Canvas + Web Audio + localStorage) для ПК и телефона. Персонажи и оружие по мотивам Alan Becker (Animator vs. Animation, Animation vs. Minecraft), режимы и управление — по мотивам Supreme Duelist Stickman. Фанатский проект.

## Запуск
Откройте `Stickman-Duel-Arena.html` (всё в одном файле) или `index.html`. APK собирается GitHub Actions (вкладка Actions → Artifacts).

## Игроки и управление (1–4 на одном экране)
Меню: «1 / 2 / 3 / 4 игрока» → лобби: у каждого слота своё управление, боец, оружие, щит, команда; сверху выбор карты, внизу «⚙ Настройки боя».
| Слот | Управление |
|---|---|
| ⌨ WASD | A/D, W прыжок, S вниз, F быстрая, G сильная, H блок, E способность, Q бросок, R взять |
| ⌨ Стрелки | ←/→, ↑, ↓, K, L, J, O, U, I |
| ⌨ Numpad | 4/6, 8, 5, 1, 2, 3, 0, 7, 9 |
| 🎮 Геймпад 1–4 | стик/крест, A прыжок, X, Y, B/LB блок, RB способность |
| 📱 Сенсор 1–4 | у каждого игрока своя панель на экране (джойстик + 6 кнопок) |
| 🤖 Бот | 4 уровня сложности |
Способности: E — обычная, E+вперёд, E в воздухе, E+вниз — ультимейт (100 энергии). Клавиши переназначаются в Настройках.

## Режимы
Дуэль (2–4), Команды (А/Б), Свободный бой (до 6), Футбол, Выживание (1–4 вместе), Зомби (волны + улучшения), Турнир (7 боёв), Хаос оружия, Тренировка. Модификаторы: здоровье, скорость игры, гравитация, отбрасывание, мгновенный КО от лавы/шипов, подбор оружия, разрушаемость.

Раздел «📖 Бойцы и оружие» в меню — лор и описание каждого бойца и предмета.

## Сборка
- Один файл: `python3 tools/build_single.py` → `Stickman-Duel-Arena.html`.
- APK: `.github/workflows/build-apk.yml` (Capacitor, debug APK, ландшафт).

## Честно о ригах
Из `.nodes` читаются цвета, число узлов и акценты; скелет и анимации собственные (процедурные, гибрид анимации и рэгдолла). Импорт `.nodes` — в `js/rig.js`.

## Как добавить
- **Боец:** запись в `SD.CHARS` и `SD.CHAR_ORDER` (`js/data.js`), реализации способностей — `FN` и `AB` в `js/abilities.js`.
- **Оружие:** строка `def(id,имя,категория,{...})` в `js/data.js`; спрайт — `js/weapons.js` (mc-пиксели или `drawShape`).
- **Арена:** `arena(id,имя,{pal,build})` в `js/arena.js`.

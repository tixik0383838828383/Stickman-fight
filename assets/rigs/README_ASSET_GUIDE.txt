IMPORTANT ASSET LIMITATION
The uploaded archive contains one separately named weapon rig: The Dark Lord Sword.
It does not contain separate weapon rigs for every character or a complete Minecraft
weapon set. The game prompt should therefore support additional weapon assets and
procedural weapon attachments, without claiming those assets are already included.

For actual game rendering, each rig needs to be exported/rendered from a compatible
rig editor into transparent PNG frames or an animation atlas, unless the chosen game
runtime has a reliable .nodes importer. Keep the original .nodes files as editable
source assets.
